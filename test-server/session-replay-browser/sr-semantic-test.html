Semantic capture playground

Context: environment facts at each replay full snapshot: user agent, viewport, masking policy, visibility, focus and analytics configuration.

Visibility: hidden/visible transitions. Switch to another Chrome tab for a few seconds and return. Keyboard focus changes alone do not emit this event.

Lifecycle: pagehide, pageshow, BFCache restore, freeze, and resume browser boundaries. Browser support varies; navigate away and back to inspect page transitions.

Navigation: URL tracking plugin observations, with origin and query removed and identifier-shaped path segments templated. Change the hash route to see a navigation event.

Recording: start, stop, pause, or resume boundaries supplied by the replay SDK. Use the stop and resume buttons to inspect customer-controlled boundaries.

Interactions: click records the actionable target, accessible name, states, and rrweb node ID. Field records safe state at change or focusout; submit records form validity without reading typed text.

Keys: Escape, Enter, Tab, arrows, Home/End, Page Up/Down, function keys, and Ctrl/Meta K, P, or F. Ordinary typing and editable text are excluded. Focus a control and press Escape to inspect its target.

Resource errors: failed image, stylesheet, script, and font loads, grouped briefly by type and sanitized path. Runtime JavaScript errors and invalid CSS rules do not trigger this event.

Local transport only. No API key required and no replay data sent to Amplitude.
