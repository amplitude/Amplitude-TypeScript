Shadow Cursed Lands

Moonrise Outskirts

Light-DOM controls. Paths should never contain a shadow delimiter, flag on or off.

The Shadow-Cursed Grove

Open shadow root, depth 1. Interactive mix: button, link, labeled input, pointer-cursor div. Expect one >>> when piercing is on.

The Deep Hollow

Nested open roots at depths 2 and 3. With depth budget 3, the deepest click should emit three delimiters.

The Abyss

Eight nested open roots — past a typical maxShadowDomDepth. Over-budget clicks should resolve to the outermost in-budget host, not crash.

The Closed Gate

Closed shadow root. Autocapture cannot pierce it; composedPath retargets to the host. Must not throw.

The Twin Trees

The same id="cta" exists in the light DOM and inside an open shadow tree. The shadow click must not steal the light-DOM path (and vice versa).

The Root Brood

Id-less same-tag siblings as direct children of a shadow root. Selectors must use a :scope > child chain so they round-trip (the orange.fr case).

The Slotted Path

Light-DOM children projected through <slot>. A click on slotted content originates in the light tree — the path should stay undelimited. A click on an in-shadow sibling should pierce.

The Host that Bites

The host itself is clickable (cursor:pointer) and also wraps an inner shadow button. Click the host chrome vs the inner button.

The Cursed Form

Form, select, textarea, password, and hidden inputs inside a shadow tree. Password/hidden should stay untracked; the rest should capture.

The Forgotten Glyph

SVG (and a clickable path) inside an open shadow root.

The Late Bloom

Host is inserted ~400ms after init. Mutation observers should discover the new open root when piercing is on.

The Silent Attach

Host is already in the DOM; attachShadow runs later with no child-list mutation. Documented observer gap — clicks should still work via composedPath.

The Swarm

Many sibling open roots. Stresses one MutationObserver per discovered root plus deep querySelectorAll.

The Churning Bog

Mount and unmount open hosts in a burst. Observers should attach and not leak errors.

The Vast Forest

Builds a large light-DOM tree off-document (thousands of nodes, shadow host attached first), then inserts it in one mutation. Discovery must DFS that addedNodes batch and still find the buried open root — click the in-shadow button and expect a delimited path.
